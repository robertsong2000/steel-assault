# 钢铁突击 STEEL ASSAULT

类魂斗罗（Contra-style）横版跑射网页游戏。纯原创：关卡设计、代码、音乐均为原创；
美术为 PPToken（gpt-image-2）AI 生成的原创像素素材，经品红键控/帧提取后接入；
胜利/失败/开场 stinger 来自本地 Kenney CC0 素材库。

## 运行

需要通过本地 HTTP 服务器打开（ES Module 限制，不能直接双击 html）：

```bash
cd code
python3 -m http.server 8931
# 浏览器打开 http://localhost:8931
```

**移动端**：手机/平板访问同一地址自动启用虚拟按键（左下十字键、右下跳/射、右上暂停/金手指），
建议横屏游玩。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← / → | 移动（标题画面：选关） |
| ↑ / ↓ | 向上瞄准 / 蹲下（标题画面：切难度，空中朝下射击） |
| 触屏 | 自动启用虚拟按键（无需设置） |
| 1 ~ 5 | 标题画面快速选关 |
| F | 射击（支持八方向） |
| X / 空格 | 跳跃 |
| ENTER | 开始 / 暂停 |
| M | 静音 |

## 玩法

- 五关战役：**第 1 关 丛林**（黄昏）/ **第 2 关 雪原**（冰湖）/ **第 3 关 基地**（激光门）/ **第 4 关 战舰**（云海 + 侧风）/ **第 5 关 遗迹**（沙漠 + 流沙 + 沙虫），标题画面 ← → 或数字键直接选关
- **难度选择**：标题画面 ↑ ↓ 切换 简单（5命×0.85弹速）/ 经典（3命）/ 硬核（1命×1.2弹速）
- 玩家按关卡主题换迷彩：丛林绿 / 雪原橙 / 基地深灰夜行 / 遗迹沙漠卡其
- 每关 BGM 独立变奏（移调 + 速度）；Boss 战每 18 秒来一架补给无人机
- 一击必杀，3 条命；死亡掉落当前武器，重生短暂无敌
- 手感优化：土狼时间（离开边缘 0.1s 可跳）+ 跳跃缓冲（提前按跳落地即跳）+ 可变跳高（点按小跳/长按大跳）
- 打落**无人机**掉落补给（金属徽章图标 + 脉动光环），7 种武器 + **B 防护罩**（10 秒无敌泡，掉坑除外）：
  - **R** 步枪（初始）/ **M** 机枪（高射速）/ **S** 散弹（5 路扇形）
  - **L** 激光（穿透多个敌人）/ **G** 榴弹（抛物线 + 范围爆炸）
  - **H** 追踪导弹（自动锁敌 + 烟迹 + 爆炸）/ **F** 火焰喷射（短程持续灼烧）
- 爆炸类武器带 AOE 范围伤害、屏幕震动与打击顿帧

## 关卡

- **第 1 关 丛林**（5300px）：黄昏三层视差、水面坑、吊桥——原创手绘布局
- **第 2 关 雪原**（5600px）：雪丘起伏——岩石高台 + 阶梯平台纵向攀爬，冰湖点缀
- **第 3 关 基地**（5600px）：双层走廊——上下两层金属平台 + 激光门封路 + 酸液池
- **第 4 关 战舰**（5600px）：浮岛跳跃——小岛链 + 移动/塌陷平台摆渡 + 侧风
- **第 5 关 遗迹**（5600px）：开阔沙丘——大平地远程火力 + 两片流沙海 + 沙虫埋伏圈
- 关卡数据集中在 `js/level.js` 的 `LEVELS` 数组（地形/敌人/触发线/水面/主题），
  `setLevel(i)` 切换并同步 CFG 边界；新增一关只需往数组里加一份定义
- 敌人：跑男、自瞄炮台、掩体狙击手（第 1 关主力）
- 新兵种：**蛙跳兵**（连续高跳逼近）、**自爆滚雷**（高速滚动、近身引爆，可提前打爆）、
  **空降兵**（降落伞空降后站射）——分散在四关触发线中
- 第 2 关敌人：**雪球兵**（抛物线雪球）、**盾牌兵**（正面挡弹，需绕后/爆炸/火焰）、**寒冰无人机**（正弦飞行 + 俯冲）
- 第 3 关：敌人混搭 + **激光门**环境机关（周期明灭，低光束可跳过、高光束等熄灭）
- 第 4 关：**垂直升降平台** + **站立 0.7s 会塌陷的平台** + 缺口**侧风**（跳跃被吹偏）
- 第 5 关（加压关，敌弹提速 15%）：**流沙区**（持续下陷、减速跳不高、不动就沉没）+ **沙虫**（沙下埋伏、破土突袭）
- 每关终点 Boss 不同：第 1 关**装甲要塞**（拆双副炮 → 打爆核心）；
  第 2 关**雪怪 Yeti**（跳扑 + 冰晶冲击波【跳起躲避】+ 掷冰岩，血量过半狂暴加速）；
  第 3 关**巨型机甲**（踏地震波 + 导弹齐射 + 胸部激光【蹲下躲避】，打头全额伤害、打身体减半）；
  第 4 关**武装直升机**（高速穿梭扫射 + 悬停投弹 + 机炮扇扫，尾旋翼是弱点，被击坠后旋转坠地）；
  第 5 关**熔岩巨兽**（岩浆池潜没【无敌】↔ 浮出【输出窗口】，喷火球 + 二阶段岩浆喷泉）
- 标题画面按 **9** 即可获得 30 条命（金手指）；也保留经典秘技 ↑↑↓↓←→←→BA（彩蛋）
- 通关结算：得分 / **击杀数 / 命中率 / 通关时间 / 死亡次数**
- 开场关卡名横幅 + Boss 登场 WARNING（含 Boss 名）；暂停挂起 BGM 并显示关卡与战绩

## 素材管线（generate2dsprite + PPToken）

```
assets/raw/        PPToken 生成的原图（品红底 #FF00FF）
assets/sprites/    generate2dsprite.py 处理产物（键控/帧提取/QC meta/GIF）
assets/img/        游戏实际加载的最终图（透明帧 + 砖块 + 背景层）
assets/audio/      Kenney CC0 jingles
```

- 精灵表（玩家/跑男 2x2）：`generate2dsprite.py process --mode sheet --rows 2 --cols 2 --shared-scale`
- 单体（炮台/狙击手/无人机/Boss）：`--rows 1 --cols 1`
- 地形砖块（满格 2x2）：定制脚本按网格切分后缩放为 64px
- 背景层（远山/丛林/雪山/雪松）：品红键控转透明后裁切；天空层直接缩放至 960x540
- Boss 精灵（雪怪）：品红键控 + 内容包围盒裁切
- 重新生成某张图：替换 `assets/raw/<name>.png` 后重跑对应处理命令即可

## 技术

- 零依赖：原生 ES Module + Canvas 2D，固定步长游戏循环（60Hz）
- 音频：WebAudio 实时合成（射击/爆炸/跳跃等音效 + 原创 BGM 步进音序器）
- 渲染：AI 精灵图优先，任何素材缺失时自动回退代码手绘（见 `js/assets.js`）
- `js/config.js` 集中所有手感调参（重力/速度/射速/关卡长度等）
- `node tools/check-levels.mjs` 关卡数据校验（站位/触发线/边界/注册表，改关卡后必跑）
